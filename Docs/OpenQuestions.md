형식: `Q번호 질문 — 임시 가정 — 상태`

- Q1 개선 방향(버그 수정 위주 / 콘텐츠 추가 / 리마스터·이식) — 가정: 출시판 버그·불편부터 — 대기
- Q2 Unity 2021.3.21f1 에디터 설치(Hub, 수 GB 다운로드) 허락 — 가정: 설치 전까지 에디터 없이 되는 일(조사·설계)만 진행, 코드 교체(INPUT-1 ③~)는 설치 후 — **해결(11-21 사용자: 설치 안 하고 6000.4 로 업그레이드)**
- Q3 출시판에 저장 기능이 있었나(코드에 ES3·PlayerPrefs 호출 0, 진행은 정적 플래그뿐) — 가정: 저장 없음, 세이브 호환 제약은 해당 없음. 저장 추가는 개선 후보로 SETUP-3 에 — 대기
- Q4 I2 Localization 은 에셋(4개 언어)만 있고 코드 미사용, 문구는 한글 하드코딩·CSV — 가정: 현지화는 당장 손대지 않음 — 대기
- Q-P0a 독 지속 피해(BattleManager 독 처리) 원식 `Range(1,2)*5`=항상 5. 저자가 1~2 포함 범위로 착각한 오타로 보고 `Range(1,3)*5`(5 또는 10)로 수정. 1d3(5~15)가 더 맞는지 — 가정: 1~2, 대기
- Q-P0b 도끼 공격 `//1D8` 주석인데 `Range(1,7)+2`(3~8) 였던 5곳을 주석대로 `Range(1,9)`(1~8)로 수정(1582·1746 등 형제 줄과 동일식). 평균 피해 5.5→4.5 로 소폭 하향 — 가정: 주석 우선, 대기
