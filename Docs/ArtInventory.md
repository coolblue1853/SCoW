> 목적: 도트 아트 정리 전에 "지금 무엇이 있고 얼마나 들쭉날쭉한지" 숫자로 남긴다. 스타일 기준은 `.claude-rules/Game/ArtStyle.md`, 에셋 선택은 `Docs/AssetPlan.md`.
> 측정: `Assets/` 아래 png/psd/jpg 를 스크립트로 전수 조사(PNG 헤더 + 8비트 비인터레이스 PNG 디코드로 고유 색 수, 알파 0 제외). 서드파티 `Assets/Plugins/**` 와 CodeMonkey psd 2개는 제외.

## 2. 임포트 설정 (meta 전수)

| 항목 | 값 | 문제 |
|---|---|---|
| Filter Mode | 전부 **Bilinear(1)** (Thaleah 글꼴 2장만 Point) | 도트가 확대 때 번진다. 해상도·배율이 제각각이라 화면에서 선명도가 장마다 다름 |
| 압축 | 전부 **Compressed(1)** (495/495) | 블록 압축은 도트 가장자리 색 번짐·팔레트 오염(특히 단색 면 + 어두운 색) |
| Max Texture Size | 2048 | `DialogBox_Img`(2934 폭)·`Logo`·`Tutorial`(2196) 등 일부가 상한에 걸려 축소 가능성 |
| Mipmap | 꺼짐 | 문제 없음 |
| PPU | 전부 100 | 확대 배율이 3~8배라 "도트 1칸 = 3~8/100 유닛"으로 장마다 크기가 다름. 카메라 픽셀 퍼펙트(2D Pixel Perfect 5.1.1 패키지는 있음)와 맞물리지 않음 |
| Pixel Perfect | 패키지 설치, 씬 적용 여부 미확인 | `Main.unity` 통독 금지라 확인 안 함 — 에디터에서 확인 필요 |
| Canvas 기준 해상도 | 800×600 (`Main.unity` 의 `m_ReferenceResolution`) | 16:9 화면에서 Scale Mode 1(Scale With Screen Size) 규칙에 따라 늘어남. 도트 정수 배율 유지 불가 |

## 3. 팔레트·톤 (대표 5장 + 고유 색 분포)

- 고유 색 분포(PNG 전체 중 8비트 디코드 가능한 것): **40색 이하 386장 / 41~300색 43장 / 300색 초과 59장(Note·Tutorial·딥원 계열).** 대부분은 18~45색의 정돈된 도트다.
- 대표 지배색(4칸마다 표본, 알파 128 이상):
  - 주인공 `Player/Stand`: `#1b0808`·`#210a0a`·`#1b1b1b`(검은 붉은 옷/머리), 하이라이트 `#fefced`·`#ffffff`·`#e1dcdc`. 24색.
  - 총포상 `Gunshop/GunCase`: 암적갈색 `#200a06`·`#3d1a14`·`#2a0f0a` 바탕 + 하늘색 유리 `#b1e5f0`·`#d0f0f6`·`#a0dae6`.
  - 술집 `Bar/BarBack`: `#251216`·`#2b1717`·`#1c1116`·`#2c1a19`(자주빛 흑갈) 195색.
  - 하수도 `Sewer/LightBack`: `#221b2b`·`#1a363b`·`#164444`·`#215449`·`#2e6148`(청록·녹청 단계) 36색 이하.
  - 대화 상자 `Main/DialogBox`: **98% `#000000`, 2% `#38323b`** — 사실상 검은 사각형에 윤곽 한 줄(2색).
  - 강변 NPC `River/Kane`: 회색 `#a8a9a7`·`#7f7878` + 어두운 `#2f2727`·`#341a15`.
- 판단: 이미 **어두운 적갈색~청록 단색조 + 흰 포인트**라서 1920년대 항구 도시 호러 톤의 뼈대는 갖춰져 있다. 다만 장소마다 색 단계가 달라(술집 붉은 갈색, 하수도 청록) 통일된 마스터 팔레트가 없다.

## 4. 눈에 띄는 불일치

1. **딥원 전투 일러스트 고색**: `Battle/Enemy/DeepOne*`(Stand/Attack/Hit/Buff/Debuff) 5장 11,000~12,400색, `DeepOneSymbol` 5,268색, `Hybrid3*` 3,100~4,300색. 같은 폴더의 `CoatHybrid*`·`Hybrid2*` 는 420~530색. 딥원만 도트가 아닌 회화풍 → 가장 큰 격차이고 노출도 최고(클라이맥스 적).
2. **도트 배율 혼재**: 주인공 8배, 배경·UI 5~6배, 지도 3~5배, 일부 4배 → 한 화면에 도트 크기가 두 종류 이상. 주인공이 배경보다 도트가 약 1.3~1.6배 큼.
3. **필터·압축**: 위 2절.
4. **수첩 텍스처**: `Note` 가죽·종이는 4,700색 이상 사진/회화 텍스처. 수첩은 장시간 노출 UI. 도트 UI 틈에서 이질적.
5. **튜토리얼 캡처**: 게임 화면을 찍은 2196×1234 이미지(7,000색 이상, 구 UI 상태). UI 를 바꾸면 전부 무효가 된다.
6. **대화상자**: 윤곽이 거의 없는 검은 상자(위 3절). 대사 노출이 가장 잦은데 프레임·장식이 없음.
7. **글꼴**: TMP `ThaleahFat`·`pcsenior` 둘 다 한글 글리프 없음. 타이틀 등 한글 표시는 폴백 글꼴 의존(현재 폴더에 한글 TMP 에셋이 없음. `MapoAgape.ttf` 는 TMP 에셋으로 변환돼 있지 않음 — `Font` 폴더에 해당 에셋이 없음). I2 Localization 으로 한글 문구를 쓰려면 한글 도트 글꼴이 필요.
8. **파일 위생**: `Sprite/New Folder`(전투 캐릭터 초상 11장), `Script/_` psd 2개(서드파티), `Screenshots` 8장이 정리 안 됨.

## 5. 다듬기 우선순위 (플레이어 노출 × 품질 격차)

노출: 상 = 거의 모든 플레이 시간, 중 = 특정 장면 반복, 하 = 한 번. 격차: 상 = 스타일 이탈, 중 = 해상도·색 불일치, 하 = 사소.

| 순위 | 대상 | 노출 | 격차 | 방법 | 사용자 검토 |
|---|---|---|---|---|---|
| 1 | 대화상자·HUD 프레임(`Main/DialogBox`·상자·버튼 등) | 상 | 상 | UI 프레임 신규 도트(ArtStyle UI 톤) — 에셋 후보 `Docs/AssetPlan.md` 1절 | 필수 |
| 2 | 임포트 설정(Point + 무압축 + 정수 배율 + 카메라 격자) | 상 | 상 | 전부 같은 메타 규칙 일괄 시험 → 스크린샷 비교. 이미지 변경 없음 | 필수(화면이 달라짐) |
| 3 | 한글 도트 글꼴 TMP 에셋 | 상 | 상 | 한글 도트 글꼴(OFL) TMP 동적 에셋을 `ThaleahFat` 폴백에 연결 | 필수(글꼴 시안) |
| 4 | 딥원 전투 일러스트(`DeepOne*` 5장 + 심볼, `Hybrid3*`) | 중(전투·엔딩) | 상 | 도트로 재제작(PixelLab 11-25 이후) 또는 색 줄이기 + 윤곽 정리 시험 | 필수 |
| 5 | 주인공 스프라이트 배율(8배→배경 배율 6배 상당) | 상 | 중 | 논리 해상도 맞춤 재도트 또는 PPU 보정 시험 | 필수 |
| 6 | 수첩(Note) 텍스처 | 중~상(수첩 열람) | 중 | 도트 톤 텍스처로 교체 또는 색 줄이기 | 필수 |
| 7 | 장소 배경 팔레트 통일(술집·총포상·하수도 …) | 상(장소별) | 중 | 마스터 팔레트에 맞춘 리컬러 시험(`ArtStyle.md` 6절) | 필수 |
| 8 | 튜토리얼 캡처 | 하(첫 플레이) | 중 | UI 최종 확정 뒤 재촬영 | 필수 |
| 9 | 컷신 일러스트 19장(100색, 510×290) | 하(스토리 장면) | 하 | 현 상태 유지, 후순위 | — |
| 10 | 파일 위생(`New Folder`, `Screenshots`, `MapoAgape.ttf` 이동) | — | — | 이름·경로 정리는 meta GUID 보존 필요(`unity-traps`) | — |

- 1~3번은 이미지 에셋을 새로 만들지 않아도 되는(또는 보유 에셋으로 해결되는) 작업이라 PixelLab 한도 11-25 이전에도 시안까지 준비 가능.
- 4번은 PixelLab(11-25 이후)에서 가장 먼저 쓸 대상 후보. 상세 설정은 생성 전에 사용자에게 먼저 묻는다(`ArtStyle.md` 8절).

## 6. 미확인·추정

- 씬에서 실제 노출되는 스프라이트 크기·카메라 배율은 `Main.unity` 통독 금지 방침상 미확인(에디터 스크린샷으로 확인 필요).
- 고색 PNG 일부(DeepOne 등)는 AI 생성물인지 직접 그린 것인지 파일만으로 알 수 없음(추정: 회화풍 그림).
- `New Folder` 11장(244~320×416, 4배)은 전투 캐릭터 초상으로 추정(파일명 미확인).
- 압축 값은 meta 첫 `textureCompression` 항목(기본 플랫폼) 기준. 플랫폼별 override 는 미분석.
