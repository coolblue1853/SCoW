## 신체 손상(LIMB-1, `Game/LimbLoss.md` 0-0절·5절)

상태: **미착수**. 자동 생성 금지, 생성은 사용자와 협의(주말 그래픽 작업). 구현 중에는 색 사각형 임시 스티커를 쓴다.
11-28 사용자 결정으로 범위를 줄였다. 결손 대상은 양손·양팔·양다리와, 얼굴은 눈·혀뿐이다. 머리·몸통 결손은 뺐다.
방식: **통짜 스프라이트 + 스티커 덮기**를 추천한다(사용자 확정 대기). 레이어 분리는 Project B 실패 이력으로 비추천이다. 스티커는 모션 프레임별 앵커 표(데이터)를 따라간다.
