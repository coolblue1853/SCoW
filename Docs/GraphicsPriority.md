# 그래픽 작업 우선순위 (11-28, 픽셀렙 세션 전달용)

- 원본 목록은 `Docs/GraphicsNeeds.md`다. 이 문서는 그 목록을 **작업 순서**로 다시 줄 세운 것이다.
- 규칙은 그대로다. 생성 전에 상세 설정을 사용자에게 먼저 묻는다. 결과는 사용자 검토 후에만 게임에 넣는다. PixelLab은 낭비하지 않는다.
- 스타일 기준은 `.claude-rules/Game/ArtStyle.md`(320×180·6배 격자, 팔레트 램프, 1921년 아캄 도트 호러)다.
- 순서 기준:
  1. 지금 정하지 않으면 나중에 다시 만들어야 하는 결정

  4. 가끔 보이는 것
