# SCoW 아트 스타일 (초안, 2026-11-21)

> 초안이다. 사용자 검토 전에는 **규칙이 아니라 제안**이다. 확정은 시안 판(`spartan:draft-board`)에서 사용자가 고른 뒤.
> 형식만 `Reference/PixelLab/ArtStyle.md`(Project B)를 참고했다. **Project B 그림체(메이드 인 어비스풍 어비스 팔레트·32px 횡스크롤·검정 외곽선 없음)를 그대로 쓰지 않는다.** SCoW 는 1921년 아캄(Arkham) 항구 도시의 탐정 호러다.
> 근거 실측: `Docs/ArtInventory.md`(현 그래픽 현황·불일치), 에셋 선택: `Docs/AssetPlan.md`.
> 연출 레퍼런스: `Reference/LimbusReference.md`(림버스 컴퍼니). 우리 도트 탐정 호러 분위기와 함께 쓴다.
> **그래픽(스프라이트·UI·글꼴 교체)은 사용자가 시안을 검토한 뒤에만 게임에 적용한다.**

## 1. 한 줄 방향

**어두운 잉크색 바탕, 가스등·전구의 호박빛 한 점, 하수도·바다의 병든 청록, 피처럼 어두운 붉은 포인트.** 도트는 선명하고 격자는 하나(정수 배율). 연출(림버스식)은 도트로 형태를 잡고 셰이더·타이밍·텍스트로 긴장을 만든다. 귀엽거나 판타지스러운 도트는 금지.

- 세계: 1921년 7월 아캄. 사립탐정 사무소, 술집, 총포상, 병원, 신문사, 경찰서, 슬럼, 강변, 하수도(딥원·크툴루 의식). 시대감은 중절모·코트·신문·타자기·가스등·전구·수첩.
- 톤: 현실의 도시가 서서히 어긋난다. 안정(밝은 호박 실내)에서 불안·위험(SAN 하락)으로 갈수록 색이 빠지고 청록·적색이 번지고 화면이 흔들린다.
- 하지 않는 것: 둥근 치비 얼굴, 밝은 원색, 판타지 소품(마법진·엘프·갑옷), 사실적 회화 일러스트(현 딥원 일러스트가 이 문제), 안티앨리어싱·블러.

## 2. 해상도·격자 (제안 — 현재 3~8배가 섞여 있음)

실측: 배경·UI 대부분 6배(원본 도트 1칸=6px), 주인공 8배, 지도 3~5배, 하수도 5배. 필터는 Bilinear, 압축 켬.

| 항목 | 제안 | 근거 |
|---|---|---|
| 논리 해상도 | **320×180** (1920×1080 에서 **6배**, 4K 에서 12배) | 현재 대다수 에셋이 6배라 재작업이 가장 적다 |
| 도트 배율 | **전 화면 6배 하나**. 3·4·5·8배 에셋은 6배로 재제작·재샘플(최근접으로만, 블러 금지) | 한 화면 한 격자 |
| PPU | 100 유지(캔버스 UI 기준), 도트 1칸 = 6/100 유닛 | 기존 설정 유지가 안전 |
| 필터/압축 | Point + 무압축(또는 고품질) | 도트 번짐·압축 색 오염 방지. **화면이 달라지므로 시안 확인 후 일괄 적용** |
| 카메라 | 2D Pixel Perfect(설치됨) 적용 여부 에디터 확인, 정수 배율 스냅 | 씬 확인 전이라 미확정 |
| Canvas 기준 | 현재 800×600 Scale With Screen Size. 도트 UI 는 정수 배율이 깨지므로 기준 해상도를 1920×1080 으로 올리는 안을 시안으로 검증 | 미결, 사용자 확인 |

- 배경 폭 예: 술집 `BarBack` 1935 → 논리 322. 한 장면은 논리 320~540 폭을 좌우 스크롤하는 구조로 유지.
- 해상도는 PixelLab 한 번에 생성 가능한 한도(캔버스 긴 변 ≤96 / 208 / 256, `Reference/PixelLab/PixelLabEconomy.md`)를 넘으므로 큰 배경은 **조각 생성 후 조립**하거나 직접 도트로 한다.

## 3. 팔레트

현 그래픽의 대표 색(`ArtInventory.md` 3절)이 이미 방향에 가깝다: 암적갈색(술집·총포상 `#200a06`~`#3d1a14`), 자주 흑갈(`#251216`), 청록 단계(하수도 `#164444`~`#2e6148`), 텍스트 흰색(`#fefced`).

- **마스터 팔레트: 32색 이하**(현 장면은 보통 18~45색). 장면 하나는 마스터에서 16~24색만 쓴다.
- 3개 계열 램프(램프당 4단: 암·중·명·하이라이트).
  1. **실내(호박·적갈)**: `#1b0808`·`#3d1a14`·`#8a4a2a`·`#e8b866`(가스등/전구). 술집·사무소·총포상·병원 실내.
  2. **야간 바깥(청회·자주)**: `#120b15`·`#221b2b`·`#4a5a6a`·`#a8b8c0`. 강변·항구·슬럼·거리.
  3. **하수도·심해(청록·녹청)**: `#164444`·`#215449`·`#2e6148`·`#78c8b0`(생물발광 한 점). 딥원은 이 계열 + 젖은 회청 피부.
- **포인트 색**(화면당 1~2곳): 호박 `#e8b866`(광원), 병든 청록 `#78c8b0`(초자연), 탁한 적색 `#7a1a1a`(피·위험·SAN 하락 UI). 순수 흑 `#000000` 은 대사창 면 하나 외에 쓰지 않는다(현재 대사창이 98% 순흑).
- **SAN 연동**: 안정은 호박 비중↑, 불안은 청회·자주 비중↑, 위험은 채도 하락 + 적색 포인트. 구현은 셰이더/오버레이(`SewerImprove.md` 3-3 `SanVisuals`)가 맡고 원본 스프라이트 색은 바꾸지 않는다.
- 위 헥스는 **초안 값**이다. 시안 판에서 사용자가 고르면 확정하고 이 절을 갱신한다.

## 4. 명암·외곽선·디더링

- **명암**: 장면당 **광원 1개**를 정한다(가스등/전구/창). 램프 4단 이하. 먼 곳은 명도·채도를 낮춘다(공기원근, 안개는 가로 줄무늬 반투명 2겹).
- **외곽선**: 배경 소품은 외곽선 없이 면으로 분리. **인물·적은 어두운 윤곽 1px**(순흑 말고 가장 어두운 램프색 `#1b0808`)으로 배경에서 분리한다. 근거: 어두운 배경이 많아 인물 실루엣이 묻힌다(현재 주인공 지배색이 `#1b0808`·`#1b1b1b`라 배경과 비슷함 — 주인공은 빛 받는 면의 하이라이트(`#fefced`)로 분리하는 현재 방식과 병행).
- **디더링**: 인물·UI 금지. 빛·안개·물에만 2×2 체커 제한 허용. 임의 노이즈 금지(Project B 판정: 잔무늬가 "디테일 많다"의 정체).
- **반사**: 젖은 바닥·물에 위아래 반사(색 한 단계 어둡게). 하수도·강변의 핵심 분위기.

## 5. 캐릭터 비율·실루엣

- Project B 의 **2등신 데포르메 규칙은 적용하지 않는다**. SCoW 인물은 **현실 비율 도트(약 6~7등신), 단순화한 면 처리**.
- 크기(6배 격자 기준 논리 픽셀): 성인 서 있는 인물 **키 56~72px**(현재 주인공 스프라이트 232×416px = 도트 29×52 @8배, PPU 100 기준 높이 4.16유닛. 같은 화면 높이를 6배 격자로 환산하면 약 69px). 얼굴은 3~4px 단위로 표정은 눈·입 1~2px만.
- 실루엣으로 구분: 탐정 = 중절모+롱코트, 의뢰인·기자 = 숄·모자, 경찰 = 제복 모자, 딥원 = 긴 사지·굽은 등·물 젖은 반투명 광택. 이름 없는 단역은 팔레트 스왑으로 만든다.
- 적(딥원·하이브리드): 격차가 가장 큰 항목(`ArtInventory.md` 4절). **회화풍 일러스트를 도트 격자로 재제작**한다. 12,000색 → 24색 이하. 형태는 어류+인간, 큰 비대칭 눈, 비늘은 하이라이트 점으로만.
- 앵커: 현 SCoW 주인공 `Sprite/Player/Stand/*`(24색, 8배)와 `CoatHybrid*`(≈430색은 줄여야 함)·`Hybrid2*`. 새 캐릭터는 이 앵커의 비율·명암에 맞춘다.
- 모션 원칙은 `Reference/PixelLab/MotionTheory.md` 중 **키 자세 + 짧은 프레임 + 방향 고정**을 따른다(전투 연출은 8절 림버스 문법).

## 6. UI 톤

- **재료감**: 수첩, 신문, 타자기 종이, 가죽, 황동. 현 수첩 텍스처(4,700색 이상 사진풍)는 도트 톤으로 재제작 대상.
- **면**: 어두운 잉크면(`#1b0808`~`#221b2b`) + 1px 황동/바랜 금색 테두리(`#8a6a3a`) + 안쪽 1px 하이라이트. 모서리는 각지게(림버스 UI 차용: 각진 프레임, 가는 라인, 큰 숫자).
- **대화상자**: 현재 순흑 사각형. 어두운 잉크면 + 황동 테두리 + 좌상단 이름표(탭) + 우하단 진행 표시(▼ 깜빡임). 초상은 별도(후순위).
- **글꼴**: 한글 = Galmuri 계열(`AssetPlan.md` 2-2), 영문·숫자 = Thaleah(현재). 수첩 필기는 손글씨체 후보(마포애가페, 라이선스 확인 후).
- **텍스트색**: 본문 `#fefced`, 이름 호박 `#e8b866`, 위험·SAN 하락 `#7a1a1a`→`#c04040`(가독성 확인), 이탤릭 대신 색·`<wave>`/`<shake>`(Text Animator).
- **입력 표시**: 마우스·키보드·패드 3경로 모두(`KeywordUX.md` 3-3의 장치별 안내). 버튼 아이콘은 도트 3종 세트(키보드·패드 A/B·마우스).
- **상태 아이콘**: `Debuff` 폴더의 6배 도트 아이콘과 같은 톤을 유지(현재 4색 평면). 새 아이콘은 4~8색.

## 7. 연출 원칙 (림버스 컴퍼니 + 도트 탐정 호러)

`LimbusReference.md` 에서 가져오는 것은 **문법**(타이밍·구도·색 구성)이고 그림을 가져오지 않는다. 컨텐츠(스토리·수치)는 사용자가 정한다.

1. **도트로 형태, 셰이더·파티클로 디테일.** 스프라이트는 선명한 격자 그대로 두고, 빛 번짐(블룸)·흔들림·색 수차·글리치는 셰이더/Volume 이 맡는다(All In 1 Sprite Shader 후보, `AssetPlan.md`).
2. **키 포즈를 길게 잡고, 포즈 사이에 흐림 전환 1프레임.** 보간 프레임은 최소. 전투 공격·피격·대사 중 인물 모션 모두 적용(림버스 스킬 동작: 준비 자세 약 0.33초 유지 → 전환 2~3프레임 → 타격 자세 유지).
3. **한 번의 큰 타격과 멈춤.** 판정 성공·실패·대성공·대실패 순간은 짧은 정지(히트 스톱 0.08~0.15초) + 화면 흔들림 + 숫자 확대. 평소에는 조용하다(대비로 긴장 만들기).
4. **판정 연출(주사위)**: 롤렛 → 정지 → 결과 숫자 확대·색(성공 호박, 실패 적색, 대성공 청록 번쩍) → 효과음 한 번. CoC 의 핵심이라 연출 비용을 여기에 쓴다.
5. **SAN 연동**: 위험 구간에서 색 빠짐·미세 흔들림 0.5%·환청 전조 소리(`SewerImprove.md` 3-3). 원본 에셋은 바꾸지 않고 오버레이·셰이더로만.
6. **텍스트 연출**: 컷인·강조 대사는 큰 글자 + 일시 정지(림버스의 스토리 연출 참고). 일반 대사는 타자기 속도 `SettingsData.TextCps` 를 따른다.
7. **장면 전환**: 페이드(검정 대신 `#120b15`) 0.3~0.5초. 장소 이동 시 장소 이름 카드(타자기체).
8. **연출은 끄거나 줄일 수 있다**: 화면 흔들림·번쩍임 배율 설정(접근성). 판정과 무관한 장식은 입력을 막지 않는다.

## 8. PixelLab 사용 원칙

- **PixelLab 생성은 11-25(사용량 리셋) 이후에 시작한다.** 지금 잔액(251/2,000 추정)으로는 신규 외형 생성을 하지 않는다. 잔액 60 미만이면 신규 외형 중단(`PixelLabEconomy.md` 규칙).
- **생성 전에 사용자에게 상세 설정을 먼저 묻는다**: 대상(딥원·주인공 변형·NPC·배경 조각·UI), 캔버스 크기, 외곽선 유무, 팔레트(위 3절 램프에서 선택), 방향, 프레임 수. 합의 없이 생성하지 않는다.
- 순서: ① 시안 판(작게, 2장) → ② 사용자 검토 → ③ 합격작만 확대 생성. 지표로 먼저 거른 것만 사용자에게 보인다(`CharacterPixelRules.md` 판정 지표).
- **결정적 작업은 코드로**(재채색·색 수 제한·정렬·잡티·격자 환산·팔레트 스왑). 5 gen 편집으로 하지 않는다. 변형은 팔레트 스왑 우선.
- 생성 전후 `get_balance` 로 비용 기록. 우선 생성 후보: 딥원 전투 일러스트 5장(`ArtInventory.md` 5절 4번).
- **적용은 사용자 검토 후에만.** 게임 에셋 교체는 시안 승인 → 스크린샷 비교(`spartan:unity-render`) → 반영 순서.

## 9. 작업 순서 (제안)

1. 임포트 설정·배율 통일 시험(이미지 변경 없음, 스크린샷 전후 비교) — 사용자 검토.
2. 한글 폰트 TMP 폴백(`AssetPlan.md` 3절 1번) — 사용자 글꼴 시안 검토.
3. 대화상자·HUD 프레임 시안 2~3판(도트 직접 또는 PixelLab) — `draft-board` 로 판 운영.
4. 딥원 전투 일러스트 재제작(11-25 이후).
5. 수첩·튜토리얼·장소 배경 팔레트 통일.
